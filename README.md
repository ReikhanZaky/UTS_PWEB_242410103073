# UTS Pemrograman Web - Website Pemenang Giveaway Kopiko

## 📝 Penjelasan Singkat Proyek
Website ini adalah aplikasi simulasi pengumuman pemenang Giveaway (undian berhadiah) dari Kopiko. Proyek ini dibangun sebagai pemenuhan tugas UTS mata kuliah Pemrograman Web. 

Aplikasi ini menggunakan framework **Laravel** dengan arsitektur **MVC (Model-View-Controller)** dan **Database MySQL**. Tema pengelolaan yang dipilih adalah "Daftar Pemenang Kopiko" dengan desain antarmuka *Dark Mode* beraksen warna emas (Gold) untuk memberikan kesan mewah.

## ✨ Fitur Utama
1. **Login Multiuser**: Sistem login menggunakan username dan password yang terhubung langsung ke database.
2. **Dashboard**: Menampilkan pesan selamat datang dan menampilkan hadiah spesifik yang dimenangkan oleh user yang sedang login.
3. **Lihat Pemenang (Pengelolaan)**: Menampilkan tabel daftar pemenang (nama, asal kota, dan hadiah) yang diambil dari database menggunakan perulangan `@foreach` di Blade.
4. **Profil**: Menampilkan data diri pemenang secara terpusat (nama, usia, alamat, telepon, email, kode pos) beserta tombol Logout.
